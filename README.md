# promo_bot — 3 аккаунта, посты в ~40 группах, автоответ в лс

## Запуск
1. `pip install -r requirements.txt`
2. Сессии: `API_ID=... API_HASH=... python3 auth.py` (auth.py из вашего проекта) — по разу на аккаунт.
3. Переменные: `API_ID`, `API_HASH`, `SESSION_STRING_1..3`.
4. Группы — в `groups.txt` (по одной в строке: `@name`, `t.me/name`, `t.me/+инвайт`). ID не нужны.
   Аккаунты должны уже состоять в группах: бот сам НЕ вступает (так безопаснее). Какие группы
   «не видны» ни одному аккаунту — написано в стартовом сообщении админу.
5. `python3 -u promo_bot.py` (Railway: Procfile уже есть).

## Свои расписания для групп
В `groups.txt` после ссылки через `|`: `cooldown=6` (раз в N часов), `window=9-12,18-22` (часы суток),
`acc=2,3` (только эти аккаунты). Пример: `t.me/name | cooldown=8 | window=9-12,18-22 | acc=2,3`.
Без опций действуют общие настройки. Глобальные паузы между постами и дневные лимиты работают поверх этого.
`/groups` у админа показывает правила каждой группы.

## Как работает
- Аккаунт 1 — тексты `first` («подробно в шапке профиля»), аккаунты 2 и 3 — `second` (работа/бонус, «пишите в лс»).
- Пауза между постами одного аккаунта — случайная 10–30 мин. Между постами любых аккаунтов — ещё 2.5–5 мин.
  Три аккаунта никогда не пишут «залпом».
- Одна группа — не чаще раза в 24 ч, и только одним аккаунтом за раз. Окно 9–22 (МСК), лимит 15 постов/аккаунт в сутки.
- Тексты не повторяются, пока не использован весь список; два поста подряд в одной группе не совпадут.
- Ошибки: FloodWait/PeerFlood → пауза аккаунта; запрет писать/бан → группа отключается для аккаунта; slowmode → отложено.
- Автоответ: первому написавшему в лс (раз в 7 дней на человека, отдельно на каждый аккаунт) — один из 3 вариантов текста из `dm_greeting`.
- Отчёт админу `@mannapov_ulugbek` — только с аккаунта `REPORT_ACCOUNT` (1), общие данные по всем, каждые 3 ч.
  Админ может написать любому аккаунту: `/status`, `/groups`, `/pause`, `/resume`, `/open`.
- Состояние хранится в `state.json` и бэкапится в «Избранное» аккаунта-отчётника (переживает редеплой).

## Настройки (необязательно)
`BOT_TZ`, `WINDOW_START_HOUR/END_HOUR`, `POST_GAP_MIN_MINUTES/MAX_MINUTES`, `GLOBAL_GAP_SEC`,
`GROUP_COOLDOWN_HOURS`, `DAILY_LIMIT_PER_ACCOUNT`, `REPORT_EVERY_HOURS`, `REPORT_ACCOUNT`, `ADMIN_USERNAME`, `GREET_AGAIN_DAYS`.

## Тесты
`pip install pytest && pytest -q` (23 теста, в т.ч. симуляция 3 суток на виртуальном времени).
